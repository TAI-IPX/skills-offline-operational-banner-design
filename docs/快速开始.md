## 一、准备工作（安装前确认）

在开始安装前，请确认以下几点：

**项目文件**

确认项目文件夹已完整解压到本地磁盘，文件夹内应包含 `scripts/`、`docs/`、`pyproject.toml`、`.env.example` 等目录和文件。

**硬盘空间**

| 内容 | 大小 |
|------|------|
| 项目核心依赖 | 约 300 MB |
| BiRefNet 抠图模型（可选） | 首次运行时自动下载，约 1 GB |
| 排行榜功能 Playwright 浏览器（可选） | 约 400 MB |

**网络**

部分 AI 生图后端（Gemini、gpt-image-2）需要访问境外服务。若网络受限，请确保可通过代理访问，或选择国内可直连的后端（Packy 代理、newapi.pro 等）。

**命令行工具**

- Windows：使用系统自带的「命令提示符」或「PowerShell」
- macOS：使用「终端」（Terminal）

## 二、安装 Python

项目要求 Python **3.8 或更高版本**。

### Windows

1. 打开浏览器，访问 [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. 点击「Download Python 3.x.x」下载最新版安装包
3. 运行安装包，**务必勾选底部的「Add Python to PATH」选项**，再点击「Install Now」

安装完成后，打开命令提示符，验证安装：

```
py --version
```

输出类似 `Python 3.12.x` 即为成功。

> **注意**：Windows 上必须使用 `py` 命令，不要用 `python`。Windows 的 `python` 命令可能指向 Microsoft Store 存根程序，不会实际运行 Python。本文档后续所有命令均按此规则区分平台。

### macOS

macOS 推荐通过 Homebrew 安装 Python：

```bash
# 如果尚未安装 Homebrew，先执行这行
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Python
brew install python
```

安装完成后，打开终端，验证安装：

```bash
python3 --version
```

输出类似 `Python 3.12.x` 即为成功。

> **注意**：macOS 没有 `py` 命令，所有命令使用 `python3`。本文档后续用注释标注两平台的命令差异。

## 三、安装项目依赖

打开命令行，进入项目根目录：

```
# Windows
cd 项目所在路径\skills-offline-operational-banner-design

# macOS
cd 项目所在路径/skills-offline-operational-banner-design
```

执行安装命令：

```
# Windows
py -m pip install -e .

# macOS
python3 -m pip install -e .
```

此命令会自动安装以下核心依赖：

- `Pillow` — 图像处理
- `requests` — 网络请求
- `python-dotenv` — 环境变量加载
- `google-generativeai` — Gemini API
- `opencv-python` — 计算机视觉
- `numpy` — 数值计算
- `anthropic` — Claude API（可选功能用）

安装完成后，看到类似 `Successfully installed ...` 的输出即为成功。

## 四、安装 BiRefNet 抠图模型（可选）

BiRefNet 是一个 AI 抠图模型，用于从图片中精准识别并抠出主体。**不安装也能使用项目的大部分功能**，仅在需要高精度抠图时才需要安装。

> **首次使用 BiRefNet 时**，脚本会自动从 HuggingFace 下载模型权重（约 1 GB），请确保网络畅通。

### Windows

直接运行安装脚本：

```
scripts\install_birefnet_deps.bat
```

该脚本会安装 CPU 版 PyTorch 和 BiRefNet 所需的其他依赖，体积比 GPU 版小很多，适合没有 NVIDIA 显卡的设备。

### macOS

macOS 没有 `.bat` 文件支持，手动执行以下命令：

```bash
python3 -m pip install --upgrade pip
python3 -m pip install torch torchvision
python3 -m pip install "transformers>=4.38.0,<5.0.0" "huggingface_hub>=0.20.0"
python3 -m pip install --upgrade "regex>=2024.5.0"
```

macOS 的 PyTorch 会自动适配 Apple Silicon MPS 加速，无需手动指定 CPU 版本。

也可以用 pyproject 中的可选依赖组一步完成：

```bash
python3 -m pip install -e ".[birefnet]"
```

### 排行榜功能（可选）

如果需要使用排行榜生成功能，还需要额外安装并初始化 Playwright：

```
# Windows — 安装依赖
py -m pip install -e ".[ranking]"
py -m playwright install chromium

# macOS — 安装依赖
python3 -m pip install -e ".[ranking]"
python3 -m playwright install chromium
```

## 五、配置 API Key

项目通过 `.env` 文件读取 API Key。`.env` 文件不会被提交到代码仓库，每台设备需要单独配置。

### 第一步：复制模板文件

```
# Windows
copy .env.example .env

# macOS
cp .env.example .env
```

### 第二步：编辑 `.env` 文件

用任意文本编辑器打开项目根目录下的 `.env` 文件，按需填入 API Key。

`.env` 中每行格式为 `变量名=你的key值`，去掉行首的 `#` 注释符即可启用。

### 按场景的最低配置

不同功能对 API Key 的需求如下：

**活动长图 / 战报 / 邮件长图**

这三类功能需要两类 Key 配合使用：

| 用途 | 变量名 | 说明 |
|------|--------|------|
| AI 生图（文生图/图生图） | `XINGCHENGGPT_API_KEY` | 推荐，通过 newapi.pro 调用 gpt-image-2 |
| AI 编辑（主体检测/扩图） | `PACKY7S_API_KEY` | 推荐，通过 Packy 代理调用 Gemini |

如果已有其他平台的 Key，参考下表选择对应变量：

| 平台 | 生图 Key 变量 | 编辑 Key 变量 | 命令行参数 |
|------|-------------|-------------|-----------|
| newapi.pro | `XINGCHENGGPT_API_KEY` | — | `--xingchengpt` |
| Packy（Gemini） | — | `PACKY7S_API_KEY` | `--packy7s` |
| PackyGPT | `PACKYGPT_API_KEY` | — | `--packygpt` |
| MicuAPI | `MICUAPI_API_KEY` | — | `--micugpt2` |
| 火山引擎即梦 | `VOLC_ACCESS_KEY_ID` + `VOLC_SECRET_ACCESS_KEY` | — | `--jimeng` |

常用组合：`--xingchengpt --packy7s`（gpt-image-2 生图 + Gemini 编辑）

**排行榜**

除上述 Key 外，还需要配置火山引擎即梦的 Key：

```ini
VOLC_ACCESS_KEY_ID=你的火山引擎 Access Key ID
VOLC_SECRET_ACCESS_KEY=你的火山引擎 Secret Access Key
```

### 配置示例

`.env` 文件最简配置示例（只配置一种生图后端 + 一种编辑后端即可运行）：

```ini
XINGCHENGGPT_API_KEY=sk-你的key
XINGCHENGGPT_BASE_URL=https://api.newapi.pro
XINGCHENGGPT_MODEL=gpt-image-2
XINGCHENGGPT_NO_PROXY=1

PACKY7S_API_KEY=sk-你的key
```

> **安全提示**：`.env` 文件已在 `.gitignore` 中，不会被意外提交。不要将 Key 直接写在命令行或代码中。

## 六、字体安装（macOS 专项）

Windows 系统自带「微软雅黑」，项目会自动调用，无需额外安装。

macOS 没有微软雅黑，部分功能会自动降级使用系统中文字体（苹方），但以下两个字体文件需要手动安装，否则相关功能的标题样式会出现问题。

### 需要安装的字体

| 字体文件 | 用途 |
|----------|------|
| `fonts/Aa封神榜书.ttf` | 活动长图、邮件长图主标题 |
| `scripts/assets/battle-report/fonts/造字工房启黑体.otf` | 战报标题 |

排行榜字体（`scripts/assets/ranking/fonts/` 目录下的 6 个文件）如需使用排行榜功能，也建议一并安装：

- `YouSheBiaoTiHei-2.ttf`
- `TaoBaoMaiCaiTi-Regular.ttf`
- `DingTalkJinBuTi-Regular.ttf`
- `D-DINExp.otf`
- `AlimamaShuHeiTi-Bold.ttf`
- `AlimamaShuHeiTi-Bold.otf`

### 安装方法

在 Finder 中找到字体文件，双击打开，点击「安装字体」按钮即可。

或者通过命令一次性安装项目内所有字体：

```bash
# 安装 fonts/ 目录下的字体
cp fonts/*.ttf ~/Library/Fonts/

# 安装战报字体
cp scripts/assets/battle-report/fonts/*.otf ~/Library/Fonts/

# 安装排行榜字体
cp scripts/assets/ranking/fonts/*.ttf ~/Library/Fonts/
cp scripts/assets/ranking/fonts/*.otf ~/Library/Fonts/
```

安装完成后无需重启系统，立即生效。

## 七、第一次运行测试

### 验证安装环境

先用 `--help` 参数确认脚本可以正常运行（不需要 API Key）：

```
# Windows
py scripts/run_changtu.py --help

# macOS
python3 scripts/run_changtu.py --help
```

输出参数说明列表即为成功。如果报错，检查[常见问题](#九常见问题)。

### 最小功能测试

准备一张本地图片作为 KV 头图（任意尺寸的 JPG 或 PNG 均可），执行仅合成命令（跳过 AI 生图，直接用已有图片合成）：

```
# Windows
py scripts/run_changtu.py --kv 你的图片路径.jpg -m "测试标题" -s "测试副标题" --xingchengpt

# macOS
python3 scripts/run_changtu.py --kv 你的图片路径.jpg -m "测试标题" -s "测试副标题" --xingchengpt
```

运行完成后，在 `output/` 目录下会生成一个以主标题命名的子目录，里面包含合成后的图片文件。

## 八、日常使用方法

> **命令规则**：以下所有命令，Windows 用 `py`，macOS 用 `python3`，后文统一用 `py / python3` 标注，选择对应平台的那个即可。

**全流程（AI 生成背景 + 合成）**

```
py / python3 scripts/run_full_with_custom_prompt.py -g 活动长图 --xingchengpt --packy7s \
  -m "主标题" -s "副标题" \
  --event-date "活动时间" \
  --prize-dir input/prizes \
  --rules "规则一|规则二|规则三"
```

**仅合成（已有 KV 图，跳过 AI 生图）**

```
py / python3 scripts/run_changtu.py --kv input/kv.jpg \
  -m "主标题" -s "副标题" --xingchengpt
```

### 战报

**全流程**

```
py / python3 scripts/run_full_with_custom_prompt.py -g 战报 --xingchengpt \
  --report-dir 素材目录路径 \
  -m "主标题" -s "副标题" \
  --stat-group "标题|标签|值|标签|值"
```

**仅合成（已有 KV 图）**

```
py / python3 scripts/run_battle_report.py --kv input/KV.jpg \
```

## 九、常见问题

### `py` 命令不存在（macOS）

macOS 没有 `py` 命令。所有命令用 `python3` 替换 `py` 即可。

```bash
# 示例：将
py scripts/run_changtu.py ...
# 替换为
python3 scripts/run_changtu.py ...
```

---

### Windows 输入 `python` 后打开了应用商店

这是 Windows 的 Microsoft Store 存根问题。解决方法：

- 直接用 `py` 命令代替 `python`
- 或在「管理应用执行别名」设置中关闭 Python 的应用商店跳转

---

### API Key 配置了但运行时报 401 错误

检查以下几点：

1. 确认 `.env` 文件在项目根目录（与 `pyproject.toml` 同级）
2. 确认 Key 行首没有 `#`（`#` 开头的行是注释，不会被读取）
3. Windows 用户还需检查系统级环境变量是否覆盖了 `.env` 的值：

```powershell
# 查看是否有系统级变量（PowerShell）
[Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'User')

# 如果有值且不是你想用的 Key，删除它
[Environment]::SetEnvironmentVariable('GEMINI_API_KEY', $null, 'User')
```

---

### API 返回 503 或请求超时

模型服务暂时不可用，或网络不稳定。解决方法：

- 稍等几分钟后重试
- 检查代理设置是否正常
- 尝试换用其他后端（如 `--packygpt` 换成 `--micugpt2`）

---

### BiRefNet 模型下载失败

BiRefNet 权重文件存储在 HuggingFace，国内访问可能较慢或失败。

- 确保网络可以访问 `huggingface.co`（必要时开启代理）
- 下载失败后重新运行命令即可续传，无需重新开始

如果暂时无法解决网络问题，跳过 BiRefNet 安装，使用不需要抠图的流程即可正常使用项目大部分功能。

---

### macOS 字体显示异常

症状：合成结果中标题字体看起来不对（比如变成了系统默认字体）。

原因：项目字体文件未安装到系统字体库。

解决方法：按照[第六章](#六字体安装macos-专项)的步骤安装字体文件。安装后重新运行即可。

---

### 排行榜运行报错：找不到 Playwright 或浏览器

需要在安装依赖后额外初始化 Playwright 浏览器：

```
# Windows
py -m playwright install chromium

# macOS
python3 -m playwright install chromium
```

---

### 输出目录没有生成结果文件

检查命令行终端中是否有报错信息。常见原因：

- API Key 未配置或配置错误（看到 `401`/`403` 错误）
- 指定的素材目录或文件路径不存在（检查 `--kv`、`--prize-dir` 等参数的路径是否正确）
- 网络请求失败（看到 `timeout` 或 `ConnectionError`）
